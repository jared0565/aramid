**Evidence grades used below**
- **[V]** verified first-hand this session (file read or command run by the controller).
- **[A]** reported by a read-only audit agent with file:line; not re-read by the controller. Verify
  before acting (`verify-before-repeating`).

**Priority**
- **BLOCKER** -- required by the 1.0 gate, or 1.0 would freeze a contract that is wrong, undeclared
  or unpinned, or ship a security-relevant falsehood in the docs.

  limitation is documented.
- **ACCEPT** -- document as a known limitation; no code.

## Global constraints (every task inherits these)

- TDD at unit scope: pins in `tests/unit/test_<stem>_<aspect>.py` (unique basename; `pytest --co tests`
  before staging). See RED first.
- Per-fix rule: stage-1 sweep against the generator's mutants (`stage1_sweep.py`, naming the UNIT file);
  replicate the CI latent-mutant ratchet locally (expect 0 files over); CHANGELOG entry;
  `aramid check --staged`; commit via `-F` file; quiet push; CI 7/7 by full sha.
- A pin that compares two computations is perturbed by ADDING a member in a scratch copy, never by
  breaking one; a hand-list checked against itself proves nothing.
- Never `--no-verify`. Never `pip install -e .`. Releases only on the operator's word. PyPI approval is
  the operator's. Stay inside this repository; other repos' work goes to their agent via the channel
  (re-list immediately before posting).
  *SUPERSEDED 2026-10-04 by the operator rule: tools are used only as tools, and the agent channel
  carries only bug reports and improvement suggestions addressed to a tool; nothing is routed to
  another repo's agent.*
- Anything in `src/aramid/` (incl. templates, help strings, docstrings) reaches consumers only through
  release + promote. `README.md` is the PyPI page and updates only at a release.
- A template change (`ARAMID.md`, hook shims) additionally needs every consumer to re-run `aramid init`
  -- announce it on the channel with the release.
  *The announcement is SUPERSEDED 2026-10-04 by the operator rule: aramid's agent posts no release
  announcements. Consumers learn of the change from the release, and the template's own text
  tells them to re-run `aramid init` after upgrading.*
